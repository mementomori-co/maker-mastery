# Fusion 360 Personal Use licence: what it allows and restricts

Applies to: any printer · Autodesk Fusion, Personal Use licence (pages read 2026-10-04; licence terms change, re-check before relying on them)
Verified: 2026-10-04

This is a summary of public pages, not legal advice.

## Facts
- Eligibility: free for individuals on non-commercial personal projects, with less than $1,000 USD of annual revenue; not for primary employment, company environments or commercial training. - [Autodesk: Fusion for personal use](https://www.autodesk.com/products/fusion-360/personal)
- The stop-use trigger is an OR: you must convert to a paid subscription if you earn more than $1,000 a year or use Fusion for a commercial project, even below $1,000. - [Autodesk: Fusion for personal use](https://www.autodesk.com/products/fusion-360/personal)
- Eligible uses named by Autodesk: non-commercial personal design projects, and home-based non-commercial manufacturing and fabrication. - [Autodesk help: Do I qualify](https://help.autodesk.com/view/fusion360/ENU/?caas=caas%2Fsfdcarticles%2Fsfdcarticles%2FDo-I-qualify-for-free-use-of-Fusion-360.html)
- The licence runs 3 years and is renewable. You can renew only when fewer than 30 days remain; a renew dialog appears at 20 days left. - [Autodesk help: renew](https://help.autodesk.com/view/fusion360/ENU/?caas=caas%2Fsfdcarticles%2Fsfdcarticles%2FHow-to-renew-your-hobbyist-enthusiast-license-for-Fusion-360.html)
- Listed limitations: limited CAM, single-user data management, limited electronics/PCB, limited 2D drawings, forum support only, limited import/export file types. - [Autodesk: Fusion for personal use](https://www.autodesk.com/products/fusion-360/personal)
- Format table (a blank "Personal Use" cell means commercial-only): STEP, SMT, F3D, 3MF, FBX, OBJ, SPD, STL and USD (usdz) are checked under both "Personal Use" and "Export". SAT and SMT Binary are checked under Export only. IGES and SVG are checked under Personal Use only (import, no export). - [Autodesk help: supported file formats](https://help.autodesk.com/view/fusion360/ENU/?guid=TPD-SUPPORTED-FILE-FORMATS)
- A check in both columns is not proof that File > Export works on Personal Use: DXF is checked in both, yet the same page says File > Export DXF is commercial-only. - [Autodesk help: supported file formats](https://help.autodesk.com/view/fusion360/ENU/?guid=TPD-SUPPORTED-FILE-FORMATS)
- Commercial-only formats (blank Personal Use cell): 123D, Alias, CATIA V5, Pro/E-Creo, Rhino, Siemens NX, Solid Edge, SolidWorks (sldprt/sldasm), Parasolid (x_t), Pro/E Granite, Pro/E Neutral, SAT, SMT Binary, TSM, AutoCAD DWG, Fusion CAM, Autodesk Eagle, Fusion Electronics. Inventor, SketchUp and the drawing template (f2t) are checked in both columns; JT is import-only. - [Autodesk help: supported file formats](https://help.autodesk.com/view/fusion360/ENU/?guid=TPD-SUPPORTED-FILE-FORMATS)
- DWG and SAT are unavailable on Personal Use for import as well as export. ACIS/SAT import is capped at ACIS version 7 on any licence. - [Autodesk help: supported file formats](https://help.autodesk.com/view/fusion360/ENU/?guid=TPD-SUPPORTED-FILE-FORMATS)
- DXF on any licence, including Personal Use: right-click a sketch in the browser and use Export DXF. - [Autodesk help: supported file formats](https://help.autodesk.com/view/fusion360/ENU/?guid=TPD-SUPPORTED-FILE-FORMATS)
- A "Personal - Not for Commercial Use" flag appears when a commercial licence has not been assigned or synced; it removes paid features and adds an editable document limit. - [Autodesk help: Personal - Not for Commercial Use](https://help.autodesk.com/view/fusion360/ENU/?caas=caas%2Fsfdcarticles%2Fsfdcarticles%2FPersonal-Not-for-Commercial-Use-in-Fusion-360-despite-a-commercial-license.html)
- Inactivity: Fusion content counts as inactive after more than 365 days without a login, and may become inaccessible 365 days after that; log in at least once a year. - [Autodesk: offering types and benefits](https://www.autodesk.com/company/terms-of-use/en/offering-types-and-benefits)
- Active documents (2020 source): a 2020 Autodesk blog defined 10 editable documents open at once, unlimited archived documents, read-only opening of inactive referenced documents, and no count for PDFs, images, presentations and spreadsheets. - [Autodesk blog: changes to Fusion for personal use (2020)](https://www.autodesk.com/products/fusion-360/blog/changes-to-fusion-360-for-personal-use/)
- CAM (same 2020 blog): 2, 2.5 and 3-axis milling available; 3+2, 4 and 5-axis subscription-only; no automatic tool change; rapids limited to cutting feedrate. - [Autodesk blog (2020)](https://www.autodesk.com/products/fusion-360/blog/changes-to-fusion-360-for-personal-use/)

## In practice
- Treat "non-commercial" as the real gate, not the $1,000 figure.
- For a part that needs DWG or SAT, convert it elsewhere first; Personal Use opens neither.
- Before relying on File > Export for STEP, STL, OBJ, 3MF or F3D, do one real test export on your own seat.
- For DXF, use Export DXF from a sketch in the browser.
- Do not rely on "10 active documents" as current; archive designs you are not editing.
- Renew inside the 30-day window; the 20-day dialog is your reminder.

## Not verified / open questions
- No Autodesk page found defines "commercial project".
- Selling prints or files under $1,000 a year is not shown as allowed by any Autodesk page. A circulating claim that it is comes from a community site (productdesignonline.com), not Autodesk, and is often misattributed to hpacademy.com.
- Whether 10 is still the active-document number: only the 2020 blog gives a number; the current help page only says an editable document limit exists.
- Whether Personal Use can export STEP, SMT, F3D, 3MF, FBX, OBJ, SPD, STL or USD through File > Export: not settled by the format table (see the DXF counter-example).
