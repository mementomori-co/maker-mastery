# P1S vs H2C: official spec limits
Applies to: both · Bambu Studio 02.08.02.61 (profiles at tag v02.08.02.61) · firmware P1 series 01.10.00.00 (20260330), H2C 01.02.00.00 (20260601)
Verified: 2026-10-03

## Facts
- **Build volume / printable area.** P1S marketed 256 x 256 x 256 mm, but the slicer profile allows only Z 250 mm (`printable_height` 250, inherited from `fdm_machine_common.json`; the P1S presets do not override it). - [P1S tech specs PDF](https://store.bblcdn.com/s7/default/9e9c1948dd61491199a52c3f1497b9c7/bambu-lab-P1S-tech-specs.pdf), [fdm_machine_common.json](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/machine/fdm_machine_common.json), [Bambu Lab P1S 0.4 nozzle.json](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/machine/Bambu%20Lab%20P1S%200.4%20nozzle.json)
- H2C marketed: single-nozzle 305 x 320 x 325 mm; dual-nozzle 300 x 320 x 325 mm; total envelope for both nozzles 330 x 320 x 325 mm. The slicer profile matches the 330 x 320 bed and 325 mm height (`printable_area`, `printable_height`). - [H2C spec PDF](https://store.bblcdn.com/s7/default/d741f5a073c94245885065ff89a0b2da/H2C_Spec.pdf), [Bambu Lab H2C 0.4 nozzle.json](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/machine/Bambu%20Lab%20H2C%200.4%20nozzle.json), [fdm_bbl_3dp_002_common.json](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/machine/fdm_bbl_3dp_002_common.json)
- **Max hotend temperature.** P1S 300 C; H2C 350 C (stock nozzles). - [P1S tech specs PDF](https://store.bblcdn.com/s7/default/9e9c1948dd61491199a52c3f1497b9c7/bambu-lab-P1S-tech-specs.pdf), [H2C spec PDF](https://store.bblcdn.com/s7/default/d741f5a073c94245885065ff89a0b2da/H2C_Spec.pdf)
- **Max bed temperature.** P1S 100 C; H2C 120 C. - [P1S tech specs PDF](https://store.bblcdn.com/s7/default/9e9c1948dd61491199a52c3f1497b9c7/bambu-lab-P1S-tech-specs.pdf), [H2C spec PDF](https://store.bblcdn.com/s7/default/d741f5a073c94245885065ff89a0b2da/H2C_Spec.pdf)
- **Chamber heating.** The P1S chamber is not actively heated: its temperature follows the bed setting and cannot be precisely controlled. The H2C has active chamber heating, max 65 C. - [P1 FAQ wiki](https://wiki.bambulab.com/en/p1/manual/faq), [H2C spec PDF](https://store.bblcdn.com/s7/default/d741f5a073c94245885065ff89a0b2da/H2C_Spec.pdf)
- **Nozzle sizes/material.** P1S: 0.4 mm included, 0.2/0.6/0.8 mm optional, stainless steel stock. H2C: 0.2/0.4/0.6/0.8 mm supported (the AMS Combo ships 0.2/0.4/0.6 only; 0.8 is supported but not included), hardened steel. The H2C machine presets set `nozzle_type` to hardened steel. - [P1S tech specs PDF](https://store.bblcdn.com/s7/default/9e9c1948dd61491199a52c3f1497b9c7/bambu-lab-P1S-tech-specs.pdf), [H2C spec PDF](https://store.bblcdn.com/s7/default/d741f5a073c94245885065ff89a0b2da/H2C_Spec.pdf), [machine presets at v02.08.02.61](https://github.com/bambulab/BambuStudio/tree/v02.08.02.61/resources/profiles/BBL/machine)
- **Filament classes.** P1S (stock stainless nozzle): PLA/PETG/TPU/ABS/ASA/PVA/PET "ideal", PA/PC "capable", carbon/glass-fibre reinforced "not recommended". H2C: PLA, PETG, TPU, PVA, BVOH, ABS, ASA, PC, PA, PET, PPS, plus CF/GF-reinforced PLA/PETG/PA/PET/PC/ABS/ASA/PPA/PPS (spec PDF wording); the store spec table words the CF/GF list slightly differently, same substance. - [P1S tech specs PDF](https://store.bblcdn.com/s7/default/9e9c1948dd61491199a52c3f1497b9c7/bambu-lab-P1S-tech-specs.pdf), [H2C spec PDF](https://store.bblcdn.com/s7/default/d741f5a073c94245885065ff89a0b2da/H2C_Spec.pdf), [H2C store](https://us.store.bambulab.com/products/h2c)
- **Toolhead speed/acceleration (maximums, not print defaults).** P1S 500 mm/s, 20 m/s2. H2C 1000 mm/s, 20,000 mm/s2. - [P1S tech specs PDF](https://store.bblcdn.com/s7/default/9e9c1948dd61491199a52c3f1497b9c7/bambu-lab-P1S-tech-specs.pdf), [H2C spec PDF](https://store.bblcdn.com/s7/default/d741f5a073c94245885065ff89a0b2da/H2C_Spec.pdf)
- **Max volumetric flow.** P1S 32 mm3/s (condition: Bambu ABS, 280 C, 150 x 150 mm single-wall test, stock 0.4 mm nozzle). H2C 40 mm3/s (condition: Bambu ABS, 280 C, 250 mm round single-outer-wall test; hotend type, standard vs induction, not stated). - [P1S tech specs PDF](https://store.bblcdn.com/s7/default/9e9c1948dd61491199a52c3f1497b9c7/bambu-lab-P1S-tech-specs.pdf), [H2C spec PDF](https://store.bblcdn.com/s7/default/d741f5a073c94245885065ff89a0b2da/H2C_Spec.pdf)
- **Original AMS (used with the P1S): 4 filament slots per unit**, each with its own feed motor. Supported: PLA, PETG, ABS, ASA, PET, PA, PC, PVA (dry), BVOH (dry), PP, POM, HIPS, Bambu PLA-CF/PAHT-CF/PETG-CF. Unsupported: TPE, TPU, PVA (wet), BVOH (wet), Bambu PET-CF/TPU 95A, other-brand CF/GF filaments. Moisture control: air-tight seal + desiccant + humidity sensor; no heater is named, and P1 firmware ties drying presets only to the AMS 2 Pro/AMS HT, so treat it as "no active drying documented", not a direct "no heater" statement. - [X1 wiki, intro AMS](https://wiki.bambulab.com/en/x1/manual/intro-ams), [AMS store page](https://us.store.bambulab.com/products/ams-multicolor-printing), [desiccant status wiki](https://wiki.bambulab.com/en/knowledge-sharing/desiccant-status), [P1 firmware history](https://wiki.bambulab.com/en/p1/manual/p1p-firmware-release-history)
- **AMS 2 Pro (1 unit ships with the H2C AMS Combo): 4 filament slots per unit**, each with one feeder. Up to 4 AMS 2 Pro + 8 AMS HT can be connected on the H2 series (24 slots). Drying max 65 C, reached only when ambient is above 25 C. Supported filament list matches the original AMS plus TPU, with the same unsupported list otherwise. - [AMS 2 Pro intro/connection guide](https://wiki.bambulab.com/en/ams-2-pro/manual/intro-and-connection-guide), [AMS 2 Pro store page](https://us.store.bambulab.com/products/ams-2-pro), [multi-model AMS compatibility](https://wiki.bambulab.com/en/ams/manual/multi-model-ams-compatibility-guide)
- The base H2C ships with no AMS; only the AMS Combo / Laser Full Combo includes 1 AMS 2 Pro (plus 8 hotends). - [H2C store FAQ](https://us.store.bambulab.com/products/h2c)
- **H2C AMS Combo hotend set:** right side (induction) 4 x 0.4 mm hardened steel (1 pre-installed, 3 in the box) + 1 x 0.2 mm + 1 x 0.6 mm induction in the box; left side (standard) 2 x 0.4 mm hardened steel (1 pre-installed, 1 in the box). Firmware does not yet support mixing nozzle sizes in one print; mixed flow types at the same diameter are fine. - [H2C store FAQ](https://us.store.bambulab.com/products/h2c)
- **Firmware, newest as of 2026-10-03.** P1 series 01.10.00.00 (20260330); printers below 01.09.01.00 must first install an offline "Bridge Firmware" (01.09.01.00). H2C 01.02.00.00 (20260601), previous 01.01.05.00 (20260211); some H2C 01.02.00.00 features need Bambu Studio 2.5.3 or later. - [P1 firmware history](https://wiki.bambulab.com/en/p1/manual/p1p-firmware-release-history), [H2C firmware history](https://wiki.bambulab.com/en/h2c/manual/h2c-firmware-release-history)
- **Bambu Studio printer presets.** P1S: `Bambu Lab P1S.json` + 0.2/0.4/0.6/0.8 nozzle variants + templates. H2C: `Bambu Lab H2C.json` + 0.2/0.4/0.6/0.8 nozzle variants + templates. - [machine presets at v02.08.02.61](https://github.com/bambulab/BambuStudio/tree/v02.08.02.61/resources/profiles/BBL/machine)

## In practice
- Do not trust the marketed 256 mm Z for the P1S when planning a tall part: the slicer profile caps it at 250 mm.
- H2C dual-nozzle Z and the shared envelope have an official store-vs-wiki mismatch (see [h2c-architecture.md](h2c-architecture.md)); plan to 320 mm Z until Bambu reconciles it.
- The H2C 40 mm3/s flow figure comes from a Bambu ABS single-wall test with the hotend type unstated; do not assume it applies equally to both hotends.
- The original AMS cannot dry filament; for active drying use an AMS 2 Pro/AMS HT or an external dryer.
- The AMS 2 Pro's 65 C drying max needs more than 25 C ambient; a cold room caps it lower.
- Check your installed profile version: values above are read from the public v02.08.02.61 source tag, and profile updates can change them.

## Not verified / open questions
- Whether the original AMS truly has no heater, or simply does not document one: no official page states "no heater" directly.
- H2C spec PDF vs store spec table word the CF/GF filament list slightly differently; not reconciled into one official wording.
- H2C dual-nozzle max Z: store 325 mm, wiki 320 mm (see [h2c-architecture.md](h2c-architecture.md)).
