# AMS 2 Pro auto-refill (AMS filament backup) and drying while printing, H2C
Applies to: H2C (AMS 2 Pro on the right/upper inlet) · Bambu Studio 02.08.02.61 (source tag v02.08.02.61) · H2C manual V1.0 2026.01 · printer firmware not checked
Verified: 2026-10-16

UI locations below come from reading the Bambu Studio C++ source at tag v02.08.02.61, not from viewing the running app.

## Facts
- Turn it on: Device tab > AMS Settings dialog > toggle "AMS filament backup" (`AMSSetting.cpp` L183). Its description says the AMS continues automatically to another spool with the same filament properties when the current one runs out. If the toggle is off, the Auto Refill dialog tells you that AMS filament backup is not enabled and to enable it in the AMS settings. - [AMSSetting.cpp](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/slic3r/GUI/AMSSetting.cpp), [AmsMappingPopup.cpp](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/slic3r/GUI/AmsMappingPopup.cpp), [BambuStudio.pot v02.08.02.61](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/bbl/i18n/BambuStudio.pot)
- Where the Auto Refill dialog opens: the "Auto Refill" link in the Send print dialog (`SelectMachine.cpp` L465) and the "Auto-refill" button on the Device tab AMS panel (`AMSControl.cpp` L201). The dialog defines identical filament as "same brand, type and color" and lists the order in which backup spools are used. The strings make no RFID / non-RFID distinction. - [SelectMachine.cpp](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/slic3r/GUI/SelectMachine.cpp), [AMSControl.cpp](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/slic3r/GUI/Widgets/AMSControl.cpp), [StatusPanel.cpp](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/slic3r/GUI/StatusPanel.cpp)
- On the printer touchscreen, the Filament screen item 5 selects auto refill and AMS setup functions (manual section 1.2.4, p.20). The manual p.53 line about controlling Auto Refill describes the Bambu Studio Device tab, not the printer screen. - [H2C manual V1.0 PDF](https://csm.bblcdn.com/hub/eff78da43720461787dc8bbe5fa0372d.pdf)
- Behaviour: when one slot's filament is used up, the printer switches to another roll of the same filament, provided the slots' filament properties match and AMS Filament Backup is on. This is stated on an X1 HMS page; no fetched page states it for H2C + AMS 2 Pro (the Studio strings above support it generically). - [X1 HMS 0700_2000_0003_0002](https://wiki.bambulab.com/en/x1/troubleshooting/hmscode/0700_2000_0003_0002)
- A warning string that an auto-refill group "may be insufficient for this print" exists only in the master-branch POT file, not in tag v02.08.02.61, so Studio 2.8.2.61 does not show it. - [master POT](https://raw.githubusercontent.com/bambulab/BambuStudio/master/bbl/i18n/BambuStudio.pot), [v02.08.02.61 POT](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/bbl/i18n/BambuStudio.pot)
- Drying presets, Bambu PLA Basic / PLA Matte: AMS 2 Pro 45 C, 12 h; AMS HT 45 C, 12 h; forced-air oven 50 C, 8 h; printer heatbed (H/X series, P2S, P1S) 60-70 C, 12 h, flip every 6 hours; drying "Recommended", desiccant "Not required but recommended". - [Bambu wiki, dry filament, Appendix I](https://wiki.bambulab.com/en/filament-acc/filament/dry-filament)
- Choosing the filament type on the printer sets the default drying temperature and duration (manual Step 4, p.124). Static drying is not suitable for PLA, PVA, Support for PLA/PETG or TPU. - [H2C manual V1.0 PDF](https://csm.bblcdn.com/hub/eff78da43720461787dc8bbe5fa0372d.pdf), [dry filament, section 1.3](https://wiki.bambulab.com/en/filament-acc/filament/dry-filament)
- Non-RFID spools show "?" in the AMS and default to PLA during drying; tap "Edit" or "Re-read" to confirm the filament info before drying. - [AMS 2 Pro drying function](https://wiki.bambulab.com/en/ams-2-pro/manual/drying-function)
- Humidity: filament stays dry only when stored below 20% RH; at about 55% RH, freshly dried filament takes up enough moisture to affect quality within 2-12 hours depending on type (generic, not material-specific). - [dry filament](https://wiki.bambulab.com/en/filament-acc/filament/dry-filament)
- Textured PEI Plate, PLA presets (Generic PLA @BBL H2C, Bambu PLA Matte @BBL H2C): initial layer 55 C and other layers 55 C, inherited from `fdm_filament_pla.json` (key `textured_plate_temp`). Studio tooltip: a value of 0 means the filament does not support that plate. The plates page says Textured PEI adheres strongly in most cases without adhesive; glue may be needed for PC/PA/ABS/ASA (PLA not in that list). - [fdm_filament_pla.json](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/filament/fdm_filament_pla.json), [PrintConfig.cpp](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp), [Bambu wiki, plates](https://wiki.bambulab.com/en/filament-acc/acc/plates)
- Drying presets, PETG (written for Bambu filament lines; applying them to other brands is an inference): row "PETG, PETG-CF" AMS 2 Pro 65 C, 12 h; AMS HT 65 C, 12 h; forced-air oven 60-65 C, 8 h; printer heatbed 75-85 C, 12 h; drying "Recommended". While printing PETG (or drying PETG while printing ABS) the AMS drying temperature is set to 55 C; drying PETG while printing PLA sets 45 C, and PLA/TPU must be removed from the AMS before drying ABS/PETG. - [dry filament](https://wiki.bambulab.com/en/filament-acc/filament/dry-filament), [AMS 2 Pro drying function](https://wiki.bambulab.com/en/ams-2-pro/manual/drying-function)
- The PETG preset key `filament_dev_ams_drying_temperature` is a 4-value array (65, 65, 55, 55) with 12 h per entry; what each of the 4 entries means is not documented. - [Generic PETG @BBL H2C.json](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/filament/Generic%20PETG%20@BBL%20H2C.json) and its parent presets in the same folder
- Textured PEI Plate, PETG (Bambu material table): 60-80 C; glue stick or liquid glue recommended; open the front door and/or remove the top glass when the bed is above 60 C, glass removal "Recommended" above 70 C. The plates page instead says Textured PEI usually needs no adhesive (glue named only for PC/PA/ABS/ASA): the two wiki pages differ. - [Bambu wiki, material table](https://wiki.bambulab.com/en/general/filament-guide-material-table), [Bambu wiki, plates](https://wiki.bambulab.com/en/filament-acc/acc/plates)

## In practice
- Set the backup spool to the same brand, type and colour as the running one, enable "AMS filament backup" in AMS Settings, and check the Auto Refill dialog before sending.
- Do not plan on drying the AMS that is printing, or its refill partner, while a job runs (H2C manual rule; see the conflict below).
- Verify on your own printer: on-screen wording and refill behaviour depend on firmware.

## Not verified / open questions
- Official rule for matching non-RFID spools (how "brand" is set, whether "Generic" counts, colour tolerance): not verified. Community only: a forum thread advises setting all spools to the same brand and colour and reports that "Generic" may not match. - [Bambu forum (community)](https://forum.bambulab.com/t/auto-refill-with-non-bl-filament/248756)
- CONFLICT, drying while printing: the H2C manual p.123 section 8.3.2 says drying is automatically disabled for AMS units involved in the current print or in an auto-refill relationship with them. The wiki dry-filament page agrees in section 1.1, but section 1.4 on the same page says drying continues at a lowered temperature (45 C for PLA). The manual is the H2C-specific source; the section 1.4 behaviour is unverified for the H2C. - [H2C manual V1.0 PDF](https://csm.bblcdn.com/hub/eff78da43720461787dc8bbe5fa0372d.pdf), [dry filament](https://wiki.bambulab.com/en/filament-acc/filament/dry-filament)
- The dry-filament page gives PLA 45 C 12 h in an AMS 2 Pro; the X1/P1-series AMS 2 Pro page gives a manual PLA range of 45-55 C, 6-8 hours. Different printer family; not the H2C path. - [AMS 2 Pro drying in X1/P1 series](https://wiki.bambulab.com/en/ams-2-pro/ams-2-pro-for-drying-in-x1-p1-series)
- Meaning of the 4 entries of the PETG `filament_dev_ams_drying_temperature` array: not found; read the Studio drying code before relying on it.
- On-screen wording and placement not viewed (source only). Both features are firmware-dependent.
