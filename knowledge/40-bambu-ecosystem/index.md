# 40 Bambu ecosystem - index

How Bambu Lab printers connect, update and take add-ons: connection modes, Bambu Connect, Farm Manager, firmware and the H2 laser kits, from the Bambu wiki, store and blog. Firmware and app versions change often; re-check the linked page before you rely on a version number. In this library the AI never starts, sends, uploads or queues a print or laser job; the maker presses the button.

- [connection-modes-and-bambu-connect.md](connection-modes-and-bambu-connect.md) - Cloud, LAN Only and Developer Mode per model, the Authorization Control System's restricted and unrestricted commands, Bambu Connect features and platforms, Bambu Handy listings, firmware status for H2C and P1.
- [farm-manager-and-print-sending.md](farm-manager-and-print-sending.md) - Bambu Farm Manager 3.0.0 requirements, firmware minimums, queue and Start All behaviour, filament matching, licensing, ports, Fleet Hub, and the real Bambu Studio send-button labels.
- [firmware-update-downgrade-and-beta-program.md](firmware-update-downgrade-and-beta-program.md) - H2C and P1 firmware notes, the P1 Bridge Firmware rule, Handy downgrade flow, the beta program, offline microSD updates, and which Bambu Studio release notes state minimum firmware.
- [h2-laser-kits-and-laser-safety.md](h2-laser-kits-and-laser-safety.md) - H2 Laser Upgrade Kit compatibility and contents, 10 W vs 40 W, Class 4 module / Class 1 system, interlocks, exhaust, laser-unsafe materials, cited standards, Bambu Suite processing types.
