# Strength tab: every setting (Process preset)
Applies to: both (H2C, P1S) · Bambu Studio 02.08.02.61 (source tag v02.08.02.61). Values below are read from the H2C chain `0.20mm Standard @BBL H2C` -> `fdm_process_dual_0.20_nozzle_0.4` (DUAL020) -> `fdm_process_dual_common` (DUALCOMMON) -> `fdm_process_common` (COMMON); the keys themselves are Process-preset settings, not printer-specific.

### Walls
- Wall loops `wall_loops`: preset **2**. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp); [COMMON](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/process/fdm_process_common.json); [Wall generator wiki](https://wiki.bambulab.com/en/software/bambu-studio/wall-generator)
- Alternate extra wall: not set -> **false**. Adds a wall on alternating layers for bonding and strength at less cost than a full extra wall. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp)
- Embedding the wall into the infill: not set -> **false**. Connects the wall into the infill where wall loops are absent. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp)
- Detect thin wall `detect_thin_wall`: preset **false**. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp); [COMMON](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/process/fdm_process_common.json)

- Interface shells `interface_shells`: preset **false**. PrintConfig.cpp tags it category "Quality" even though it is drawn on Strength. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp)
- Top surface pattern `top_surface_pattern`: preset **Monotonic line** (code default Rectilinear). See [pattern-selection-guide.md](pattern-selection-guide.md) for the option list and the stored-value trap. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp); [COMMON](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/process/fdm_process_common.json); [Fill patterns wiki](https://wiki.bambulab.com/en/software/bambu-studio/fill-patterns)
- Top surface density `top_surface_density`: preset **100 %** (fully solid); lower values give a textured top, and 0 % prints only walls on the top layer. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp)
- Top shell layers `top_shell_layers`: code default 4, COMMON sets 3, DUAL020 sets **5**. Top shell thickness `top_shell_thickness`: code 0.6 mm, COMMON 0.8, DUAL020 **1.0 mm**. Top paint penetration layers `top_color_penetration_layers`: **5** (DUAL020). -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp); [DUAL020](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/process/fdm_process_dual_0.20_nozzle_0.4.json)
- Bottom surface pattern `bottom_surface_pattern`: preset **Monotonic**; shares the top pattern's option list. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp); [COMMON](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/process/fdm_process_common.json)
- Bottom surface density `bottom_surface_density`: preset **100 %**. The tooltip (four joined strings) says lower values give a textured bottom for looks or function, not to fix over-extrusion, and warns that lowering it may hurt bed adhesion. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp)
- Bottom shell layers **3**; Bottom shell thickness **0 mm** (0 = only the layer count decides); Bottom paint penetration layers **3**. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp); [COMMON](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/resources/profiles/BBL/process/fdm_process_common.json)
- Use infill instead of top and bottom surfaces `infill_instead_top_bottom_surfaces`: preset **false**. Shown only while Strength > Sparse infill > Sparse infill pattern = Locked Zag. -- [PC](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/libslic3r/PrintConfig.cpp); [CM](https://raw.githubusercontent.com/bambulab/BambuStudio/v02.08.02.61/src/slic3r/GUI/ConfigManipulation.cpp)

## In practice
- Pattern choice by part type: [pattern-selection-guide.md](pattern-selection-guide.md).
- Many infill rows only appear for one pattern (Locked Zag, Zig Zag, Cross Zag, 2D Lattice). Read the `toggle_line` calls in ConfigManipulation.cpp before deciding a row is gone; the Locked Zag wiki page documents five of these sub-settings.
- "Filter out tiny gaps" is Develop mode only.
- A "not set" row still has a real code default; it never means "off".
- Tooltips are often split across several joined C++ strings. Quote from the raw source, not from an earlier paraphrase, or you may drop a middle sentence.
- Compare `%APPDATA%\BambuStudio\system\BBL\process\` with the tag files before trusting these values on your install.
