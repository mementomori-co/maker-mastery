# Lesson 03: check every rule and feature against your own printer model

Area: printers and hardware claims

| What happened | Root cause | Rule now |
|---|---|---|
| Print sheets and an audit check told the maker to open the front door or remove the top glass when printing PLA, based on a printer-generic filament guide. The maker's printer has an automatic top vent that opens in its PLA cooling mode, so the instruction was wrong for that machine. | A rule from a printer-generic table was written into printer-specific sheets and checks without reading that printer's own manual. The fact-check asked "does the page say this?" and never "does this apply to this printer?". | Every operating rule in a print sheet or audit check is tagged with the printer model it was verified for. A rule from a generic page is applied to a specific printer only after that printer's own manual or wiki section has been read for an override. Fact-checks of hardware or operating claims carry an "applies to this printer?" column. Audit checks that touch operation (door, glass, chamber, exhaust) branch on the printer profile. |
| A camera-streaming route was recommended because a forum post and documentation for other printer models described a "LAN liveview" setting. Scripts and a guide were built on it. On the maker's printer, the setting did not exist. | A feature backed only by community reports and by documentation for other models was made the recommended route before anyone looked at the real printer's screen. | A hardware feature that is only community-reported, or documented only for other models, is never the recommended route. Recommend the route already proven on your machine, list the unproven one as an experiment, and look at the printer's own menu before building on it. Mark the claim CONTRADICTED for that model when it fails. |

How to check: for each hardware or operating instruction in a sheet, find the source and confirm it names your exact printer model; if it does not, find the model-specific page or label the instruction "not verified for this printer".
